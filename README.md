# Baraqiyya Photo Booth

Photo booth for **Aslami Fest 2K26 – IBDA Exhibition**
Mon, Nov 23, 2026 · Daruswalah Islamic Academy, Karamoola, Mukkam, Kozhikode

## Live link

https://ashik-mangalan.github.io/Baraqiyya-photobooth/

Open it on a phone or tablet and allow camera access.

## Features

- Live camera with a 3-2-1 countdown
- Front and back camera switch
- Upload a photo instead of using the camera
- Filters: Normal, B&W, Warm, Cool
- Frame colors: Teal and Maroon
- Save or share the finished photo

## Files

- `index.html`: the whole photo booth, with the logo embedded
